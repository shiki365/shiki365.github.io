デザイン一新の案（3 方向）

置き場サイトのトップと、チャットウィンドウメーカーの画面を、方向の違う 3 つの案で作りました。どれも本物のファイルのコピーで、変えたのは <style> だけです。チャットウィンドウメーカーはそのまま動きます（書き出す CSS は元と同じです）。

A 案と C 案には、ダークとライトの 2 種類があります。ふだんは OS の設定（ダークモード・ライトモード）に合わせて自動で切り替わり、URL の末尾に ?theme=light ?theme=dark を付けると OS に関係なく選べます（下のリンクは付けてあります）。

言語は各画面の右上、または URL の末尾に ?lang=en ?lang=ko で切り替えられます（?lang=en&theme=light のように並べても使えます）。見方と細かい決まりは README.md にあります。

A 案　計器盤暗い・密度高め・線で区切る

カードをやめて、細い線と見出しの帯で区切る「道具の画面」。行を詰めて、設定が一度に多く見えます。色は琥珀 1 色だけで、数字は等幅。長時間 OBS の設定を詰める人向け。

  • チャットウィンドウメーカー（ダーク）
  • 置き場サイト（ライト）
  • チャットウィンドウメーカー（ライト）

B 案　紙と墨明るい・ゆったり・明朝の見出し

生成りの紙に墨の文字、朱の差し色。見出しはシステムの明朝体で、説明文が多いツールでも読み物として読めます。プレビューだけは暗い台紙に載せて、映りを白い紙の色に引っぱられずに見られるようにしました。

  • チャットウィンドウメーカー

#f3efe5 / 面 #fbf9f3
差し色
朱 #ad3722（ボタンは白文字）
角
2〜3px、二重線と罫

C 案　オンエア暗い・太い線・大きな文字

配信卓のような、黒地に太い枠と大きな見出し。プレビューはモニターに見立てて四隅にセーフエリアの印。選んだタブや「コピー」は黄緑のベタ塗りで、光る影の代わりに黒いずらし影。押す場所が大きく、迷いにくい案。

  • 置き場サイト（ライト）
  • チャットウィンドウメーカー（ライト）

比べるときのこつ: 3 案のチャットウィンドウメーカーは、同じサーバーで開くと作業内容（ブラウザの自動保存）を共有します。1 つの案でひな形や色を変えてから別の案を開くと、同じ設定のまま見た目だけを比べられます。
