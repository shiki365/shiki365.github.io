Free tools for CCFOLIA and online TRPG / murder-mystery streaming: scene-transition animations, foreground frames, and OBS status bars, chat windows and message boxes, plus a maker for CCFOLIA scenario texts with portraits. The browser tools need no sign-up and no install, and nothing you make is uploaded; the last one is a small app you download to link OBS with Discord. This page and all the browser tools are also in English and Korean (see the language links at the top).

ブラウザで使うツール

ページを開けばすぐに使えます。新しいものから並べています。

  • 無料
  • 会員登録なし
  • インストールなし
  • 画像や入力内容はどこにも送られません

  • シナリオテキストメーカー

    こんなときにNPC の台詞や探索箇所の描写を、ココフォリアのシナリオテキストにまとめて入れたい

    台本や描写の文章を貼ると、ココフォリアのシナリオテキストをまとめて作ります。台詞には話し手の立ち絵（表情の差分も）を、描写やハンドアウトには 1 件ずつ好きな画像を付けられ、送るとメッセージボックスに画像が出ます。できた ZIP を、ルームデータとして読み込むだけです。

    作れるもの
    ルームデータ（ZIP）
    使う場所
    ココフォリアのルーム設定（GM）
    ツールを開く ソースコード（GitHub）

  • メッセージボックスメーカー

    こんなときに配信画面に、立ち絵つきの台詞をノベルゲームのように出したい

    ココフォリアで発言するとルーム画面の下に出る、立ち絵つきのメッセージボックスを、OBS に好きなデザインで映すための CSS を作ります。ルームの盤面や駒は消えて、メッセージボックスだけが映ります。ひな形 7 種（ノベルゲーム・古い紙・SF など）から、箱・名前の札・文字・立ち絵の置き方を選び、プレビューで発言を送って確かめてからコピーできます。

    作れるもの
    OBS の「カスタム CSS」
    使う場所
    OBS のブラウザソース
    ツールを開く ソースコード（GitHub）

  • チャットウィンドウメーカー

    こんなときに配信画面に、ダイスの結果や秘匿チャットを出したい

    ココフォリアのダイスの結果や秘匿チャットを、OBS に好きなデザインで映すための CSS を作ります。窓・見出し・文字・成否の色・動き（出してから数秒で消すこともできます）を選び、プレビューでメッセージを送って確かめてからコピーできます。

    作れるもの
    OBS の「カスタム CSS」
    使う場所
    OBS のブラウザソース
    ツールを開く ソースコード（GitHub）

  • ステータスバーメーカー

    こんなときに配信画面に、キャラの HP や SAN 値を出したい

    ココフォリアのキャラの HP・MP・SAN などを、OBS に好きなデザインで映すための CSS を作ります。ひな形 10 種から形・色・文字・ピンチの演出を選んで、コピーするだけ。HP が減るほどバーにひびが入り、横に置いた宝石や花が壊れていく演出もあります。数値はココフォリアと連動して動きます。

    作れるもの
    OBS の「カスタム CSS」
    使う場所
    OBS のブラウザソース
    ツールを開く ソースコード（GitHub）

  • 前景フレームメーカー

    こんなときに盤面のまわりに、シナリオに合う枠をつけたい

    ココフォリアの前景に使う「枠」画像を作ります。角の形・色・蔦や花などの飾りを組み合わせてデザインし、天気や時間帯などの差分もまとめて書き出せます。

    作れるもの
    PNG 画像（窓の部分が透明）。差分は ZIP でまとめて
    使う場所
    ココフォリアの前景
    ツールを開く ソースコード（GitHub）

  • 場面転換素材メーカー

    こんなときに暗転やワイプで、場面を切り替える演出を入れたい

    暗転・ワイプ・アイリスから、血のしたたり・星形・水玉・サイバー系・異空間まで 53 種類の場面転換アニメーションを作ります。背景が透明なまま動くので、セッション画面の上に重ねて使えます。

    作れるもの
    動く WebP（軽い）・APNG（動く PNG 画像）
    使う場所
    ココフォリアなど、オンラインセッションの画面
    ツールを開く ソースコード（GitHub）

    対応 OS
    Windows・macOS

ブラウザのツールの使い方

ブラウザで使うツールは、どれもだいたい同じ手順です。在室灯の使い方は、配布ファイルに入っている説明書（README）を見てください。

  1. ツールを開くインストールも会員登録もいりません。
  2. ひな形を選んで、色や形を変える変えた結果は、その場でプレビューに出ます。（シナリオテキストメーカーは、台本を貼って、話し手ごとに立ち絵を登録します）
  3. 保存して、ココフォリアや OBS に入れる設定のしかたは、各ツールの画面の下に書いてあります。（シナリオテキストメーカーは、書き出した ZIP を、ココフォリアのルームデータとして読み込みます）

よくある質問

質問を押すと答えが開きます。

お金はかかりますか？

かかりません。どのツールも無料です。ブラウザで使うツールは、会員登録やインストールもいらず、ページを開けばすぐに使えます。

作った画像や CSS は、自由に使ってもいいですか？

はい、自由に使えます。ただし、ツールに読み込んだ配布素材やフォントは、それぞれの利用規約に従ってください。細かい条件は、各ツールのページのいちばん下に書いています。

在室灯は、配布ファイルに入っている利用規約に従ってください。

読み込んだ画像や入力した内容は、どこかに送られますか？

ブラウザで使うツールでは、送られません。処理はすべて、お使いのブラウザの中だけで行われます。

作りかけのデザインは残りますか？

前景フレームメーカー・ステータスバーメーカー・シナリオテキストメーカーは、作業中の内容をブラウザに自動で保存します。次に同じブラウザで開くと続きから始まります。

別のパソコンやブラウザで続けたいときは、ツールの中でプロジェクトファイルを保存し、移った先で読み込んでください。

スマホでも使えますか？

ブラウザで使うツールは設定の項目が多いため、画面の広いパソコンでの利用をおすすめします。

ココフォリアや Discord の公式ツールですか？

いいえ。個人が作った非公式のツールで、ココフォリアや Discord をはじめ、いずれのサービスとも関係ありません。ココフォリアの画面の作りが変わると、ステータスバー・チャットウィンドウ・メッセージボックスの表示が崩れることがあります。シナリオテキストメーカーは、ココフォリアのルームデータの形が変わると、読み込めなくなることがあります。

不具合を見つけたとき、要望があるときは？

このページのいちばん下の「不具合の報告・感想」から送れます。どれも匿名で、Google アカウントもいりません。
