チャットウィンドウメーカー

ココフォリアのダイスの結果や秘匿チャットを、OBS に好きなデザインで映すための「カスタムCSS」を作ります。右のプレビューでメッセージを送りながら確かめられます。すべてブラウザの中だけで処理され、入力した内容がどこかに送られることはありません。マシュマロでいただいた要望から生まれたツールです。

デザインのひな形

映すメッセージ

新しいものから数えて、この件数だけ映します。窓に入りきらない古いメッセージは端で切れます。システムメッセージは、HP や SAN を変えたとき（:HP-2 など）にココフォリアが自動で出す「[ キャラ名 ] HP : 12 → 10」のようなお知らせです。どのタブを映すかは OBS で選びます（「OBS・保存」タブを参照）。

ブラウザソースの大きさ

OBS のブラウザソースに入れる幅と高さです。窓はこの中に置かれます。

窓

「中身の大きさに合わせる」は、メッセージが少ないとき窓も小さくなり、寄せた側から伸びます。

見出し

OBS で開いているタブの名前（「メイン」や秘匿タブの名前）がそのまま出ます。プレビュー上の「映すタブ」で切り替えて確かめられます。

秘匿タブの参加者

ココフォリアは、参加者を決めた秘匿タブを開いているときだけ、そのタブに参加しているユーザーのアイコンを出します（メインなどでは出ません）。アイコンはキャラではなく、ユーザーのプロフィール画像です。間隔をマイナスにすると重なります。揃え方と文字の色・フォントは見出しと同じです。

1件ぶんの箱

「ダイスの成否の色」は、結果の色（「文字・結果」タブ）で線を引きます。ダイスでないメッセージは「線の色」になります（OBS 31 以降）。

アイコン
名前

キャラの色は、ココフォリアで発言したときの名前の色です。

本文

「長い文」を 1 以上にすると、その行数より長いメッセージは「…」で切ります。ふちどりは名前とダイスの結果にもかかります。

「名前で指定（PCのフォント）」では、この PC に入れたフォントが使えます。OBS を動かす PC にも同じフォントが入っている必要があります。

ダイスの結果
成功 失敗 その他

色の分け方はココフォリアと同じです。成功は「成功」「スペシャル」など、失敗は「失敗」と、ほかの人のシークレットダイス。成否のないロール（2D6 など）はその他になります。クリティカルとファンブルは、それぞれ成功・失敗の色です。

メッセージが来たとき
長い本文をゆっくり流す

流れるのは、映す件数が 1 件のときだけです（「メッセージ」タブ）。

日記や手紙のような長い本文を、先頭から読ませてから末尾まで流します。窓に収まる本文は動きません。
1 件表示のときだけ動き、窓はソースいっぱいになります。オンにすると件数と窓の大きさを合わせます。
長さに合わせて速さは変わらないので、長い本文ほど速く流れます。「時間がたったら消す」は、流しきってから数えます。

時間がたったら消す

窓（背景・枠・見出し）も一緒に消え、新しいメッセージが届くとまた出ます。秘匿チャットを、送ったときだけ映したいときに。
OBS の「対話」でマウスを乗せている間は、タブを選べるように窓を出したままにします（プレビューも同じなので、確かめるときはマウスを外してください）。
「ダイスの結果だけ」「システムメッセージを除く」と一緒に使うと、窓に映らない種類のメッセージが届いたときも、窓が出てしばらく残ります（秘匿タブにシステムメッセージは届きません）。

ダイス速報のように、振ったときだけ出したい場合に。消えたメッセージのぶん、ほかのメッセージが詰まります。
OBS でソースを読み込み直すと、消えていたメッセージもいったん出てから消えます。
プレビューでは設定を変えるたびに動きが最初からやり直されるので、全部消えたら右のボタンでメッセージを送ってください。

確かめ方

右の「メッセージを送って確かめる」のボタンを押すと、プレビューに新しいメッセージが届きます。動きや、件数を超えたときの入れ替わりを確かめられます。

ルーム

ココフォリアでルームを開いたときの URL を貼ると、OBS に入れるチャット画面の URL（末尾が /chat）を作ります。書き出す CSS の先頭にも書き込まれます。

OBS の「対話」

オンにすると、OBS でソースを右クリック →「対話」を開き、窓の上にマウスを乗せたときだけココフォリアのタブが出ます。秘匿タブを映すときは、ここでタブを選びます。配信の画面には出ません。

プロジェクト

作業内容はこのブラウザに自動で保存されます。ダイス用と秘匿チャット用など、いくつか作るときは「プロジェクトを保存」で分けておくと便利です。

メッセージを送って確かめる（プレビューだけ。書き出す CSS には影響しません）

OBS のブラウザソースに入れる URL（末尾が /chat のチャット画面。ルームの URL ではありません）

ルームの URL をそのまま OBS に入れると、ルームの画面（背景や駒）が丸ごと映ります。ルームの URL を入れると、ここに OBS 用の URL が出ます。

OBS での設定

  1. ソースを追加 →「ブラウザ」。URL にチャット画面の URL（末尾が /chat）を入れます：
    https://ccfolia.com/rooms/{ルームID}/chat
    ブラウザのアドレス欄にあるルームの URL ではありません。上の「OBS のブラウザソースに入れる URL」からコピーできます。
  2. 幅と高さに、上に出ている ブラウザソースの大きさ を入れます。
  3. 「カスタム CSS」の中身を全部消して、コピーした CSS を貼り付けます。
  4. 何も映らないときや秘匿タブを映すときは、ココフォリアへのログインが必要です。いったん URL を https://ccfolia.com/ にして、ソースを右クリック →「対話」でログインしてから、URL を元に戻します（1 回やれば覚えています）。「対話」ではログインだけして、ルームには入らないでください。
  5. メイン以外のタブは、「対話」を開いて窓にマウスを乗せ、出てきたタブから選びます。タブの選択は保存されないので、OBS を起動し直したら選び直してください。

うまく映らないとき

  • ルームの背景・スクリーンパネル・駒・拡大縮小のボタンまで映る → チャット画面ではなく、ルームの画面を開いています。ソースのプロパティで、URL の末尾が /chat になっているか確かめてください。「対話」の中でルームに入ってしまったときは、URL をいったん https://ccfolia.com/ にして OK → チャット画面の URL に戻して OK で直ります。
  • 何も映らない → ココフォリアへのログインが必要です（上の手順 4）。
  • 長い本文の先頭が見えない（日記や手紙など） → 窓に収まらない分は切れます。「メッセージ」タブの並び順を「新しいものを上に」にすると先頭から表示されます（今度は末尾が切れます）。件数を 1 件にし、ブラウザソースの高さを上げて、文字を小さくすると収まりやすくなります。

ダイス用と秘匿チャット用を両方出すとき

  • ブラウザソースは OBS の仕様で複製できません（右クリックの「複製を貼り付け」は灰色のままです）。「ソースを追加」→「ブラウザ」で 2 つ目を新しく作り、同じチャット画面の URL を入れて、それぞれにこのツールで作った CSS を貼り付けてください。秘匿チャット用のほうだけ、「対話」で秘匿タブを選びます。
  • ログインはすべてのブラウザソースで共通なので、2 つ目で入り直す必要はありません。大きさや位置は、右クリック →「変換をコピー」→ もう一方で「変換を貼り付け」でそろえられます。
  • 秘匿タブは、そのタブに参加しているアカウント（GM など）でログインしたときだけ見えます。
  • ブラウザソースの設定で「表示されていないときにソースをシャットダウン」「シーンがアクティブになったときにブラウザの表示を更新」をオンにすると、切り替えのたびにタブがメインに戻ります。

台詞（立ち絵つきのメッセージボックス）も映したいとき

  • ココフォリアで発言したときにルーム画面の下に出る、立ち絵つきのメッセージボックスは、姉妹ツールのメッセージボックスメーカーで OBS 用にデザインできます。
  • メッセージボックスには、ダイスの結果のうち「＞ 成功」のような最後の部分しか出ません。台詞はメッセージボックス、出目まで入ったダイスの結果はこのツール（ひな形「ダイス速報（1件を大きく）」など）と分けて映すのがおすすめです。ブラウザソースは 2 つになりますが、ログインは共通です。

PC に入れたフォントを使うとき

  • フォント欄で「名前で指定（PCのフォント）」を選び、フォント名を入れます。Chrome / Edge では「一覧から選ぶ」で、PC に入っているフォントを見た目で選べます（初回はフォントの使用の許可を聞かれます）。
  • OBS は自分の PC のフォントで表示するので、OBS を動かす PC にも同じフォントを入れてください。入っていないと、ふつうのゴシック体になります。
  • 漢字が入っていないフォントでは、漢字の部分だけふつうのゴシック体になります（一覧の見本の「永」で確かめられます）。

このツールについて

マシュマロでいただいた「ダイスウィンドウや秘匿チャットを、プレビューで確かめながらカスタマイズしたい」という声から作りました。「こんなツールがほしい」「ここが使いにくい」といった声も、マシュマロからお気軽にどうぞ。

ブラウザだけで動く無料ツールです。作った CSS は自由に使えます。
ココフォリアの画面の作りが変わると、表示が崩れることがあります。いずれのサービスとも関係のない非公式のツールです。
