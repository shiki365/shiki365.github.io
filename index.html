ブラウザで使うツール

ページを開けばすぐに使えます。新しいものから並べています。

  • 無料
  • 会員登録なし
  • インストールなし
  • 画像や入力内容はどこにも送られません

  • チャットウィンドウメーカー

    こんなときに配信画面に、ダイスの結果や秘匿チャットを出したい

    ココフォリアのダイスの結果や秘匿チャットを、OBS に好きなデザインで映すための CSS を作ります。窓・見出し・文字・成否の色・動きを選び、プレビューでメッセージを送って確かめてからコピーできます。

    作れるもの
    OBS の「カスタム CSS」
    使う場所
    OBS のブラウザソース
    ツールを開く ソースコード（GitHub）

  • ステータスバーメーカー

    こんなときに配信画面に、キャラの HP や SAN 値を出したい

    ココフォリアのキャラの HP・MP・SAN などを、OBS に好きなデザインで映すための CSS を作ります。ひな形 9 種から形・色・文字・ピンチの演出を選んで、コピーするだけ。数値はココフォリアと連動して動きます。

    作れるもの
    OBS の「カスタム CSS」
    使う場所
    OBS のブラウザソース
    ツールを開く ソースコード（GitHub）

  • 前景フレームメーカー

    こんなときに盤面のまわりに、シナリオに合う枠をつけたい

    ココフォリアの前景に使う「枠」画像を作ります。角の形・色・蔦や花などの飾りを組み合わせてデザインし、天気や時間帯などの差分もまとめて書き出せます。

    作れるもの
    PNG 画像（窓の部分が透明）。差分は ZIP でまとめて
    使う場所
    ココフォリアの前景
    ツールを開く ソースコード（GitHub）

  • 場面転換素材メーカー

    こんなときに暗転やワイプで、場面を切り替える演出を入れたい

    暗転・ワイプ・アイリスなど 18 種類の場面転換アニメーションを作ります。背景が透明なまま動くので、セッション画面の上に重ねて使えます。

    作れるもの
    APNG（動く PNG 画像）
    使う場所
    ココフォリアなど、オンラインセッションの画面
    ツールを開く ソースコード（GitHub）

ダウンロードして使うツール

パソコンに入れて動かすソフトです。BOOTH で無料配布しています。

  • 在室灯ベータ版

    こんなときに配信画面に、誰がどの部屋（通話）にいるかを出したい

    Discord のボイスチャンネルに誰がいるかを、OBS の配信画面に自動で表示します。通話の部屋を移動すると、画面の名前も一緒に動きます。表示名は PC 名にでき、GM や見学者は盤面から隠せます。

    種類
    パソコンで動かすソフト（Discord と連動）
    使う場所
    OBS の配信画面
    必要なもの
    Node.js（無料）・OBS・Discord の Bot
    対応 OS
    Windows・macOS
    BOOTH で見る

ブラウザのツールの使い方

ブラウザで使うツールは、どれもだいたい同じ手順です。在室灯の使い方は、配布ファイルに入っている説明書（README）を見てください。

  1. ツールを開くインストールも会員登録もいりません。
  2. ひな形を選んで、色や形を変える変えた結果は、その場でプレビューに出ます。
  3. 保存して、ココフォリアや OBS に入れる設定のしかたは、各ツールの画面の下に書いてあります。

よくある質問

質問を押すと答えが開きます。

お金はかかりますか？

かかりません。どのツールも無料です。ブラウザで使うツールは、会員登録やインストールもいらず、ページを開けばすぐに使えます。

作った画像や CSS は、自由に使ってもいいですか？

はい、自由に使えます。ただし、ツールに読み込んだ配布素材やフォントは、それぞれの利用規約に従ってください。細かい条件は、各ツールのページのいちばん下に書いています。

在室灯は、配布ファイルに入っている利用規約に従ってください。

読み込んだ画像や入力した内容は、どこかに送られますか？

ブラウザで使うツールでは、送られません。処理はすべて、お使いのブラウザの中だけで行われます。

作りかけのデザインは残りますか？

前景フレームメーカーとステータスバーメーカーは、作業中の内容をブラウザに自動で保存します。次に同じブラウザで開くと続きから始まります。

別のパソコンやブラウザで続けたいときは、ツールの中でプロジェクトファイルを保存し、移った先で読み込んでください。

スマホでも使えますか？

ブラウザで使うツールは設定の項目が多いため、画面の広いパソコンでの利用をおすすめします。

ココフォリアや Discord の公式ツールですか？

いいえ。個人が作った非公式のツールで、ココフォリアや Discord をはじめ、いずれのサービスとも関係ありません。ココフォリアの画面の作りが変わると、ステータスバーの表示が崩れることがあります。

不具合を見つけたとき、要望があるときは？

このページのいちばん下の「不具合の報告・感想」から送れます。どれも匿名で、Google アカウントもいりません。
